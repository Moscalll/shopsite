# ShopSite 性能测试操作说明

这份说明用于对比优化前后页面性能与业务效果，适用于后续 React + TypeScript + Vite 前端版本。

## 1. 测试目标

重点观察以下结果：

- 页面加载是否更快
- 图片是否更快出现
- 接口响应是否更稳定
- 推荐模块是否更快加载
- 业务流程是否更顺畅

## 2. 测试准备

### 2.1 环境要求

- 同一台电脑
- 同一浏览器版本
- 同一网络环境
- 同一份测试账号和测试数据
- 测试前关闭无关下载任务

### 2.2 推荐页面

优先测试以下页面：

- 首页 `/`
- 商品列表页 `/products`
- 商品详情页 `/product/{id}`
- 购物车页 `/cart`
- 结算页 `/checkout`
- 管理端统计页 `/admin/**`

### 2.3 推荐场景

每个页面都建议测 2 种场景：

- 冷启动：清缓存后第一次访问
- 热启动：已缓存后再次访问

## 3. 需要记录的指标

### 3.1 页面性能指标

- FCP：首次内容绘制
- LCP：最大内容绘制
- CLS：布局偏移
- INP：交互响应
- 页面完全加载时间
- 首屏图片请求数
- 图片总大小

### 3.2 接口性能指标

- 平均响应时间
- P95 响应时间
- P99 响应时间
- 错误率
- 超时率

### 3.3 业务效果指标

- 推荐点击率
- 加购率
- 下单成功率
- 重复提交率
- 空结果率

## 4. 测试步骤

### 步骤 1：记录优化前基线

1. 打开测试页面
2. 清空浏览器缓存
3. 运行自动化脚本
4. 保存结果到 `before` 目录或文件名中

### 步骤 2：实施优化

可逐项优化，例如：

- 图片懒加载
- 骨架屏
- 响应式图片
- 列表分页或虚拟滚动
- 推荐模块按需加载

### 步骤 3：记录优化后结果

1. 保持相同测试条件
2. 再次运行同一脚本
3. 保存结果到 `after` 目录或文件名中

### 步骤 4：对比结果

重点比较：

- LCP 是否下降
- 图片请求数是否减少
- 接口耗时是否降低
- 推荐点击率是否提升
- 下单重复提交率是否下降

## 5. 判定建议

如果满足以下条件，说明优化有效：

- 商品列表页 LCP 降低 20% 以上
- 首屏图片请求数降低 30% 以上
- 管理看板加载时间降低 20% 以上
- 推荐模块点击率提升 10% 以上
- 下单重复提交率明显下降

## 6. 结果输出建议

建议每次测试生成一个 JSON 文件，格式包含：

- 版本号：`before` / `after`
- 页面地址
- 测试时间
- 各项性能指标
- 备注

后续可导入 Excel 做对比表。

## 7. 推荐的测试顺序

1. 首页
2. 商品列表页
3. 商品详情页
4. 购物车页
5. 结算页
6. 管理端分析页

每做完一个优化点，就重复同样的顺序测试一次。
